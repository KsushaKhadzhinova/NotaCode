## 2. Функции предыдущих версий, обязательные к сохранению

- Формальная грамматика Lark, модель «узлы/рёбра», ошибки с номером строки и колонки.
- Цепочки связей `a -> b -> c`, подписанные связи.
- Тело класса `{ +field: Type  +method() }`, списки атрибутов `[key="val"]`, сохраняемые позиции `pos`.
- Monarch-подсветка синтаксиса, шаблон для каждой нотации.
- Реестр нотаций-плагинов с операцией `validate`.
- Экспорт в PlantUML, Mermaid, BPMN XML, draw.io XML; скачивание исходного файла, SVG, PNG (масштаб ×2).
- Git-подобное версионирование (Blob с SHA-256, Commit с автором user/ai), журнал AI-запросов.
- Декомпозиция IDEF0 (родительская и дочерние диаграммы), соавторы.
- AI: интерфейс провайдера и заглушка, строгий системный промпт, режим исправления кода, удаление markdown-ограждений из ответа, суточная квота.
- Kroki как внешний движок рендеринга, экспорт в GitHub Gist.
- JWT, bcrypt, интерфейс RU/EN, тёмная и светлая темы, раскладка VS Code, тосты, масштаб и «вписать».
- Очередь задач для рендеринга и AI.
- Наблюдаемость: Sentry, заголовок времени ответа, GZip.
- Черновик в localStorage, индикатор online/offline.

## 3. Выявленные дефекты и правила их исключения

| № | Дефект | Правило NotaCode |
|---|---|---|
| 1 | Функции распределены по неслитым веткам; бэкенд и UI сливаются раздельно, функции теряются между версиями | Одна основная ветка; функция сливается целиком (бэкенд, UI, тесты) |
| 2 | Три несовместимых синтаксиса DSL; AI-промпты описывают четвёртый | Одна грамматика; промпты генерируются из каталога нотаций |
| 3 | Несовпадение ключей нотаций фронта и бэка (`idef0` и `idef0.context_decomposition`) приводит к HTTP 500 | Единый каталог нотаций в `packages/contracts` |
| 4 | Грамматика допускает конструкции, отклоняемые плагином нотации | Грамматика и профили нотаций проверяются общими тестами |
| 5 | `node_modules` в репозитории, неудалённые worktrees | `.gitignore`, проверка в CI |
| 6 | Stored XSS: подписи узлов вставляются в SVG без экранирования, SVG вставляется через `dangerouslySetInnerHTML`; Mermaid с `securityLevel: 'loose'` | Экранирование на сервере, санитизация DOMPurify, `securityLevel: 'strict'` |
| 7 | API-ключ Gemini в бандле фронтенда и в URL (`?key=`) | Ключи только на сервере, передача в заголовках |
| 8 | Системный промпт и движок задаются клиентом (открытый прокси) | Промпты и движки задаются только сервером |
| 9 | Имитация авторизации `?auth=1`, секрет JWT по умолчанию | Реальная аутентификация; отсутствие секрета блокирует запуск |
| 10 | `/render` без авторизации и без ограничения размера | Rate limit и лимит размера входных данных |
| 11 | Ошибки Kroki подменяются заглушкой «Mock diagram» | Ошибки внешних систем возвращаются как диагностика |
| 12 | `datetime.utcnow()` в значении по умолчанию вычисляется однократно при импорте | Фабрики значений по умолчанию |
| 13 | Неразрешимые импорты, недостижимые обработчики ошибок, неснимаемая подсветка в Monaco | Типизация, покрытие 100%, e2e-тесты |
| 14 | Маркер стрелки BPMN используется без определения | Snapshot-тесты SVG |
| 15 | Граф dagre создаётся один раз на модуль, узлы сохраняются между раскладками | Раскладка как чистая функция |
| 16 | Правка кода регулярными выражениями | Правки только через синтаксическое дерево и source map |
| 17 | Дублирующиеся модули (`ai_service.py` в двух местах, компонент на 1533 строки) | Ограничение размера файлов и функций линтером |
| 18 | Раскладка в одну строку | Послойная раскладка (elkjs) |
| 19 | Незафиксированные и дублирующиеся зависимости | Lock-файлы, Renovate, проверка в CI |
