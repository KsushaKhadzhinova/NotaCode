# Аудит старых версий проекта (23.09.2026)

Старые папки используются только как справочник: что уже было и какие ошибки не повторять. Код оттуда в NotaCode не копируется.

## Где лежала самая полная версия

- `E:\VisualDSL-Platform`, ветка `prod`: 4 нотации (ERD, BPMN process, UML class, IDEF0), экспорт в PlantUML, Mermaid, BPMN XML и draw.io, AI-провайдеры, версии Blob/Commit, соавторы, декомпозиция IDEF0, Alembic, rate limit, около 20 тестов. На `main` лежит только лендинг.
- `E:\VisualDSL_Project`: 12 веток, которые не продолжают друг друга. В `feature/javascript-interactivity` были рендеры Mermaid и PlantUML, экспорт SVG/PNG, черновик в localStorage. При переходе на React всё это пропало.
- `E:\my-ai-app` и `E:\PAS-project`: холст на React Flow + dagre, двусторонняя синхронизация (перетаскивание узла → `pos` в коде, клик → строка кода), панель свойств.
- `E:\visualdsl-modeling-service`: Lark, Kroki, экспорт в GitHub Gist, Gemini.
- `E:\design_udl_project`: UI-макеты режимов AI, diff версий, дашборда, документации, терминала.

## Ошибки, которые не повторяем

1. Функции разъехались по неслитым веткам. Бэкенд и UI сливали по отдельности, поэтому функции «удалялись» между версиями. Правило: одна основная ветка, каждая функция сливается целиком (бэкенд + UI + тесты).
2. Было три несовместимых синтаксиса DSL, а AI-промпты описывали четвёртый. Правило: один язык, одна грамматика, промпты генерируются из того же каталога нотаций.
3. Ключи нотаций на фронте и бэке не совпадали (`idef0` и `idef0.context_decomposition`), из-за этого пользователь получал HTTP 500. Правило: единый каталог в `packages/contracts`.
4. Грамматика принимала то, что отвергал плагин нотации.
5. `node_modules` попадал в git, оставались «мусорные» worktrees.
6. Stored XSS: подписи узлов вставлялись в SVG без экранирования, а SVG — через `dangerouslySetInnerHTML`. Для Mermaid стоял `securityLevel: 'loose'`.
7. API-ключ Gemini попадал в бандл фронта и в URL (`?key=`).
8. Клиент сам присылал системный промпт и движок — получался открытый прокси.
9. Фальшивая авторизация `?auth=1` и секрет JWT по умолчанию.
10. `/render` работал без авторизации и без лимита размера.
11. Ошибки Kroki скрывались подменой на «Mock diagram».
12. `datetime.utcnow()` в значении по умолчанию вычислялся один раз при импорте.
13. Битые импорты, недостижимые обработчики ошибок, подсветка в Monaco не снималась.
14. Маркер стрелки BPMN использовался, но не был определён.
15. Граф dagre создавался один раз на модуль, и узлы протекали между раскладками.
16. Код правили регулярными выражениями (перетаскивание → код). Правило: правки только через синтаксическое дерево и позиции узлов.
17. Дубли файлов (`ai_service.py` в двух местах, `UDLEditorComplete` на 1533 строки).
18. Раскладка в одну строку.
19. Грязные зависимости (два React Flow, неверные версии, ничего не зафиксировано).
